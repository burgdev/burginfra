# Overview

A linux server needs to be ready to run k3s. This document describes the setup of a linux server.

## Server setup

Run the [setup_server.sh](/Management/Scripts/setup_server.sh) script on the server.

```bash
ssh USER@SERVER.burgdev.ch ./scripts/setup_server.sh run_all
ssh USER@SERVER.burgdev.ch ./scripts/setup_server.sh # how help
```
